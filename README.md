# ATM Simulation Project

## Project Overview
This is a simple ATM simulation project built using Java Servlets and JSP. It provides basic ATM functionalities like checking balance, withdrawing, depositing, and viewing a mini statement.

## Features
- User authentication using ATM number and PIN
- View account balance
- Withdraw and deposit money
- View mini statement of recent transactions
- Simple and user-friendly web interface

## Technologies Used
### Frontend:
- **HTML** – Structure of the web pages
- **CSS** – Styling and layout (without Bootstrap)

### Backend:
- **Java (Servlets & JSP)** – Handles business logic and user requests

### Development Tools:
- **Eclipse/VS Code** – IDE for Java development
- **Apache Tomcat** – Server to run Servlets and JSP pages

## How to Run the Project
### Prerequisites:
- Install **JDK 8 or higher**
- Install **Apache Tomcat 8.5 or higher**  
- Install **Eclipse**  

### Steps:
1. Clone or download the project repository.
2. Open the project in **Eclipse**.
3. Configure **Apache Tomcat** in Eclipse.
4. Run the project on the server.
5. Open your browser and navigate to `http://localhost:8080/project`.
6. Use the login page to enter your ATM number and PIN.
7. Perform ATM operations like checking balance, deposit, withdraw, and mini statement.

 


## Usage
1. **Login Page** – Enter ATM number and PIN to access your account.
2. **Dashboard** – Choose an action: View Balance, Withdraw, Deposit, or Mini Statement.
3. **Withdraw/Deposit Page** – Enter an amount to perform the transaction.
4. **Mini Statement** – View recent transaction history.
